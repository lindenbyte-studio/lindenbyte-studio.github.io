Bulk PageSpeed Insights & Core Web Vitals Checker (Sitemap)

Audit hundreds of URLs or a whole sitemap with Google's official PageSpeed Insights API: Lighthouse scores, lab LCP/CLS/TBT, real-user CrUX Core Web Vitals (LCP, INP, CLS) and top fixes, mobile + desktop, with pass/fail thresholds for monitoring.

Run it on Apify

What you can do with it

  • SEO agencies: Core Web Vitals report for a client's whole sitemap in one CSV.
  • Developers: catch performance regressions after a deploy with a scheduled run and thresholds.
  • Site owners: find which templates (product pages, blog posts) have poor LCP or CLS, and what to fix first.
  • Competitor benchmarking: compare your pages with competitors' on mobile and desktop.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'urls': [   'https://www.shopify.com/',
                'https://www.bigcommerce.com/',
                'https://woocommerce.com/'],
    'strategy': 'both',
    'categories': ['performance', 'seo']}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/bulk-pagespeed-core-web-vitals").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "urls": [
        "https://www.shopify.com/",
        "https://www.bigcommerce.com/",
        "https://woocommerce.com/"
    ],
    "strategy": "both",
    "categories": [
        "performance",
        "seo"
    ]
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/bulk-pagespeed-core-web-vitals').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~bulk-pagespeed-core-web-vitals/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "urls": [
    "https://www.shopify.com/",
    "https://www.bigcommerce.com/",
    "https://woocommerce.com/"
  ],
  "strategy": "both",
  "categories": [
    "performance",
    "seo"
  ]
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
