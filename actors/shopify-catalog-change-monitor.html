Shopify Catalog & Change Monitor: Prices, Stock, New Products

Paste Shopify store domains and get their full public product catalog, or only what changed since the last run: new products, price drops, price increases, restocks, sell-outs and removed products. No browser, no login. Pay per result.

Run it on Apify

What you can do with it

  • Competitor price monitoring: watch rival stores, get a row the day a price drops or a sale starts.
  • Dropshipping and reselling: find new arrivals, restocks and sell-outs of products you resell or source.
  • Deal and restock alerts: schedule hourly/daily, filter by keyword and price_drop + restocked, push to Slack, Telegram, e-mail, Zapier or Make through Apify integrations.
  • Market research: catalogs by vendor, product type, price band, sale share, tag usage.
  • Assortment tracking for brands and retailers: which products does a stockist add or remove, which ones sell out first.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'stores': ['allbirds.com', 'gymshark.com'],
    'mode': 'changes',
    'stateKey': 'deals',
    'changeTypes': ['price_drop', 'restocked'],
    'minPriceChangePercent': 10,
    'maxProductsPerStore': 5000}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/shopify-catalog-change-monitor").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "stores": [
        "allbirds.com",
        "gymshark.com"
    ],
    "mode": "changes",
    "stateKey": "deals",
    "changeTypes": [
        "price_drop",
        "restocked"
    ],
    "minPriceChangePercent": 10,
    "maxProductsPerStore": 5000
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/shopify-catalog-change-monitor').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~shopify-catalog-change-monitor/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "stores": [
    "allbirds.com",
    "gymshark.com"
  ],
  "mode": "changes",
  "stateKey": "deals",
  "changeTypes": [
    "price_drop",
    "restocked"
  ],
  "minPriceChangePercent": 10,
  "maxProductsPerStore": 5000
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
