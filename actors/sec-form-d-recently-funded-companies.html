SEC Form D Feed: Recently Funded Companies & Private Placements

Daily feed of new SEC Form D filings: companies that just raised money in private placements. Amount raised and offered, investors, industry, state, exemption, address and phone, straight from EDGAR. Filters, only-new-since-last-run, CSV ready. Pay per filing.

Run it on Apify

What you can do with it

  • Sales prospecting: companies that just raised $1M+ have new budget for software, hiring, offices, insurance and services. Call or email them while the money is fresh.
  • Recruiting and staffing: freshly funded startups hire right after a round. Filter by state and the Technology or Health Care sector.
  • Commercial real estate, banking, insurance, payroll and accounting firms: new money means new offices, bank accounts and policies.
  • Investors and analysts: track who is raising, how much, how fast (amount sold vs. offered) and from how many investors. Filter federalExemptions: 06c for offerings that are publicly marketed.
  • Fund and SPV launches: turn off excludePooledFunds and filter by fund type (Venture Capital Fund, Private Equity Fund, Hedge Fund).
  • Local business news: all new raises in your state, every morning.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'lastDays': 3,
    'states': ['CA'],
    'industryGroups': ['Technology', 'Health Care'],
    'minAmountSold': 1000000,
    'excludeAmendments': True,
    'onlyNewSinceLastRun': True,
    'stateKey': 'task-ca-tech-health'}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/sec-form-d-recently-funded-companies").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "lastDays": 3,
    "states": [
        "CA"
    ],
    "industryGroups": [
        "Technology",
        "Health Care"
    ],
    "minAmountSold": 1000000,
    "excludeAmendments": true,
    "onlyNewSinceLastRun": true,
    "stateKey": "task-ca-tech-health"
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/sec-form-d-recently-funded-companies').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON

  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "lastDays": 3,
  "states": [
    "CA"
  ],
  "industryGroups": [
    "Technology",
    "Health Care"
  ],
  "minAmountSold": 1000000,
  "excludeAmendments": true,
  "onlyNewSinceLastRun": true,

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
