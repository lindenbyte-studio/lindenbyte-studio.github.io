Bulk Domain Availability & Expiry Checker (RDAP)

Check thousands of domains for availability, expiry date, registrar, EPP status and nameservers via official registry RDAP (every RDAP TLD), with DNS fallback for ccTLDs. Name x TLD matrix for brand hunting and a monitor mode that outputs only changes.

Run it on Apify

What you can do with it

  • Brand and startup name hunting: enter name ideas and extensions (acme, lindenbyte x com, io, ai, dev) and get the full matrix of what is free.
  • Domain portfolio audit: expiry dates, days left and registrar for every domain you or your clients own, in one table. Use expiringWithinDays to flag renewals due soon.
  • Expiry and drop monitoring: schedule the Actor in monitor mode and get only the domains that changed since the last run: a domain became available, was renewed, changed registrar or nameservers, entered redemptionPeriod / pendingDelete, or entered your expiry window.
  • Lead and research enrichment: registrar, age (creation date) and, optionally, DNS records (A, AAAA, MX, NS, SPF, DMARC) for lists of company domains.
  • Brand protection: watch typo and look-alike domains of your brand and get told when one gets registered.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'keywords': ['lindenbyte', 'northpeak', 'brightlark'],
    'tlds': ['com', 'io', 'ai', 'dev', 'co', 'app'],
    'mode': 'check'}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/bulk-domain-availability-expiry-checker").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "keywords": [
        "lindenbyte",
        "northpeak",
        "brightlark"
    ],
    "tlds": [
        "com",
        "io",
        "ai",
        "dev",
        "co",
        "app"
    ],
    "mode": "check"
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/bulk-domain-availability-expiry-checker').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON

  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "keywords": [
    "lindenbyte",
    "northpeak",
    "brightlark"
  ],
  "tlds": [
    "com",
    "io",
    "ai",
    "dev",
    "co",
    "app"
  ],
  "mode": "check"
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
