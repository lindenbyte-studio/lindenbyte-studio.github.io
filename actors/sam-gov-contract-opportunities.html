SAM.gov Contract Opportunities Scraper (RFPs & Bids)

Search US federal contract opportunities on SAM.gov by keyword, NAICS, PSC, set-aside, agency and notice type. Schedule for daily new-RFP alerts.

Run it on Apify

What you can do with it

  • Daily RFP alerts: schedule a daily run and send new opportunities to Slack, email, Google Sheets, Zapier, Make or n8n.
  • Pipeline building: pull every open solicitation for your NAICS codes in one go and load it into your CRM.
  • Market research: see which agencies buy what (by NAICS or PSC code), how often, and where.
  • Set-aside tracking: watch 8(a), HUBZone, SDVOSB, WOSB and other small-business set-asides.
  • Award tracking: include award notices to see who won and for how much.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'keywords': ['cybersecurity'],
    'noticeTypes': ['solicitation', 'combined', 'presolicitation'],
    'activeOnly': True,
    'postedWithinDays': 30,
    'maxResults': 100,
    'includeDetails': True,
    'sortBy': 'relevance'}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/sam-gov-contract-opportunities").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "keywords": [
        "cybersecurity"
    ],
    "noticeTypes": [
        "solicitation",
        "combined",
        "presolicitation"
    ],
    "activeOnly": true,
    "postedWithinDays": 30,
    "maxResults": 100,
    "includeDetails": true,
    "sortBy": "relevance"
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/sam-gov-contract-opportunities').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~sam-gov-contract-opportunities/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "keywords": [
    "cybersecurity"
  ],
  "noticeTypes": [
    "solicitation",
    "combined",
    "presolicitation"
  ],
  "activeOnly": true,
  "postedWithinDays": 30,
  "maxResults": 100,
  "includeDetails": true,
  "sortBy": "relevance"
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
