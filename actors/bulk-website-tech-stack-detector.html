Bulk Website Tech Stack Detector (7,000+ technologies)

Detect the technologies behind any list of websites (CMS, ecommerce platform, analytics, CDN, frameworks, versions) with ~7,700 open-source fingerprints, no browser. Schedule 'changes' mode to see which technologies each site added or dropped since the last run.

Run it on Apify

What you can do with it

  • Lead generation: find every store on Shopify, WooCommerce or Magento, every site running HubSpot, Klaviyo or Stripe, from a list of prospects.
  • Sales triggers: be told when a prospect adds or removes a tool you sell against or integrate with.
  • Competitor monitoring: watch which analytics, payment, chat and marketing tools competitors adopt.
  • Agency and SEO audits: bulk-check CMS, outdated library versions and tracking setup across client sites.
  • Market research: market share of platforms inside a segment, built from your own domain list.
  • Security hygiene: spot visible outdated versions (server, CMS, jQuery) on your own portfolio.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'urls': [   'allbirds.com',
                'gymshark.com',
                'bombas.com',
                'woocommerce.com',
                'kyliecosmetics.com'],
    'includeCategories': ['Ecommerce', 'Payment processors', 'CMS']}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/bulk-website-tech-stack-detector").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "urls": [
        "allbirds.com",
        "gymshark.com",
        "bombas.com",
        "woocommerce.com",
        "kyliecosmetics.com"
    ],
    "includeCategories": [
        "Ecommerce",
        "Payment processors",
        "CMS"
    ]
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/bulk-website-tech-stack-detector').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~bulk-website-tech-stack-detector/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "urls": [
    "allbirds.com",
    "gymshark.com",
    "bombas.com",
    "woocommerce.com",
    "kyliecosmetics.com"
  ],
  "includeCategories": [
    "Ecommerce",
    "Payment processors",
    "CMS"
  ]
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.

Ready-to-run example tasks

Each one opens on Apify with the input already filled in.

  • Which ecommerce platform does a store use?
    Check Shopify, WooCommerce, Magento, BigCommerce and payment tools for a list of online stores in seconds.
  • Competitor tech stack change monitor

  • CMS detector: is it WordPress, Webflow, Wix or Drupal?

    Check which cookie consent platform each website uses (OneTrust, Cookiebot, Usercentrics, Didomi, Quantcast and others) next to its analytics and tag manager.
