Sitemap Monitor: All URLs + New Pages Since Last Run

Extract every URL from any website's XML sitemaps (robots.txt discovery, indexes, .xml.gz, hreflang, images) and schedule it to get only NEW pages since the last run. Optional HTTP status and redirect check.

Run it on Apify

What you can do with it

  • Competitor monitoring: new product pages, blog posts, landing pages, locations, job pages.
  • News monitoring: new articles from publishers' Google News sitemaps, with headline and publish time, without scraping article pages.
  • SEO audits: full URL inventory, sitemap URLs that 404 or redirect, stale lastmod, hreflang coverage.
  • Content teams and agencies: weekly list of what clients or competitors published.
  • Crawling pipelines: feed only new URLs into a scraper instead of re-crawling the whole site.
  • E-commerce: new SKUs on a competitor's store the day they go live.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'sites': ['www.allbirds.com'],
    'onlyNew': True,
    'emitOnBaseline': False,
    'stateKey': 'example-products',
    'urlPattern': '/products/'}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/sitemap-monitor-new-pages").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "sites": [
        "www.allbirds.com"
    ],
    "onlyNew": true,
    "emitOnBaseline": false,
    "stateKey": "example-products",
    "urlPattern": "/products/"
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/sitemap-monitor-new-pages').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~sitemap-monitor-new-pages/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "sites": [
    "www.allbirds.com"
  ],
  "onlyNew": true,
  "emitOnBaseline": false,
  "stateKey": "example-products",
  "urlPattern": "/products/"
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
