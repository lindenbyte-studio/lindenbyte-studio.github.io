EU Public Tenders (TED) Scraper: Bids & Contract Notices

Search EU public procurement tenders on TED by keyword, country, CPV code and notice type. Official API, structured data, schedule daily for new-tender alerts.

Run it on Apify

What you can do with it

  • Daily tender alerts: schedule a daily run and send new tenders to Slack, email, Google Sheets, Zapier, Make or n8n.
  • Lead generation: find public buyers (ministries, municipalities, hospitals, utilities) looking for what you sell.
  • Bid pipeline: pull every open contract notice for your CPV codes and countries, sorted by deadline.
  • Market research: see who buys what, where and for how much, using estimated values and award notices.
  • Competitor tracking: use award notices (can-standard) to see which contracts were awarded.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'keywords': [],
    'buyerCountries': ['DEU'],
    'cpvCodes': ['72000000'],
    'publishedWithinDays': 7,
    'maxResults': 100}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/eu-ted-tenders-scraper").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "keywords": [],
    "buyerCountries": [
        "DEU"
    ],
    "cpvCodes": [
        "72000000"
    ],
    "publishedWithinDays": 7,
    "maxResults": 100
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/eu-ted-tenders-scraper').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~eu-ted-tenders-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "keywords": [],
  "buyerCountries": [
    "DEU"
  ],
  "cpvCodes": [
    "72000000"
  ],
  "publishedWithinDays": 7,
  "maxResults": 100
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
