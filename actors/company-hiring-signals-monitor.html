Company Hiring Signals Monitor: Open Jobs, New & Closed Roles

Paste company domains and get their open jobs straight from the official job-board APIs (Greenhouse, Lever, Ashby, Workable, SmartRecruiters, Recruitee, Personio). Hiring-signal summaries per company, new and closed roles since the last run. Pay per result.

Run it on Apify

What you can do with it

  • Sales and lead generation: find companies that are hiring for the role your product replaces or supports (SDRs, data engineers, DevOps, compliance) and reach out while the need is fresh.
  • Recruiting and staffing agencies: watch target accounts and get an alert the day a new role opens.
  • Competitor and market intelligence: track a competitor's or a whole sector's hiring by department, location and seniority, and see growth or freezes over time.
  • Investor and analyst research: weekly open-role counts, roles posted in the last 7/30/90 days, net change since last run.
  • Job seekers: monitor your dream companies, filter by keyword, department, location or remote.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'companies': ['stripe.com', 'notion.so', 'linear.app', 'vercel.com', 'mistral.ai'],
    'outputJobRows': False,
    'includeCompanySummary': True,
    'stateKey': 'weekly-trends'}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/company-hiring-signals-monitor").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "companies": [
        "stripe.com",
        "notion.so",
        "linear.app",
        "vercel.com",
        "mistral.ai"
    ],
    "outputJobRows": false,
    "includeCompanySummary": true,
    "stateKey": "weekly-trends"
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/company-hiring-signals-monitor').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~company-hiring-signals-monitor/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "companies": [
    "stripe.com",
    "notion.so",
    "linear.app",
    "vercel.com",
    "mistral.ai"
  ],
  "outputJobRows": false,
  "includeCompanySummary": true,
  "stateKey": "weekly-trends"
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
