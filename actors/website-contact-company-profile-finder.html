Website Contact Page & Company Profile Finder

Turn a list of domains into company profiles: contact page URL, contact form provider (HubSpot, Typeform, CF7, Gravity Forms...), about/careers/pricing/privacy pages, company social profiles, logo, favicon, name and language. No personal data. Pay only for sites that load.

Run it on Apify

What you can do with it

  • Lead list enrichment. Add the contact page, form tool, LinkedIn page and logo to a list of domains from your CRM or a scraped directory.
  • Martech prospecting. Find companies that use HubSpot, Typeform, Gravity Forms or Intercom, or have no contact form at all.
  • Partner, vendor and supplier research. Get the careers, pricing, privacy and imprint (Impressum) links for hundreds of sites in one table.
  • Brand assets. Collect logos, favicons and OG images for directories, CRMs or dashboards.
  • Data hygiene. Spot dead domains (unreachable) and broken sites in a list.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'startUrls': [   'weidert.com',
                     'wpbeginner.com',
                     'ghost.org',
                     'basecamp.com',
                     'wpshout.com',
                     'festool.de',
                     'cybozu.co.jp'],
    'maxPagesPerSite': 5,
    'probeCommonPaths': True}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/website-contact-company-profile-finder").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "startUrls": [
        "weidert.com",
        "wpbeginner.com",
        "ghost.org",
        "basecamp.com",
        "wpshout.com",
        "festool.de",
        "cybozu.co.jp"
    ],
    "maxPagesPerSite": 5,
    "probeCommonPaths": true
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/website-contact-company-profile-finder').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~website-contact-company-profile-finder/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "startUrls": [
    "weidert.com",
    "wpbeginner.com",
    "ghost.org",
    "basecamp.com",
    "wpshout.com",
    "festool.de",
    "cybozu.co.jp"
  ],
  "maxPagesPerSite": 5,
  "probeCommonPaths": true
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
