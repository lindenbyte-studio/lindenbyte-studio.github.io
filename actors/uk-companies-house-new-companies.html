UK Companies House New Company Finder (Leads by SIC & Date)

Find newly incorporated UK companies from the official Companies House API: filter by incorporation date, SIC code, status, type, location and postcode. Company-level data with SIC descriptions, registered office, accounts due dates. Schedule daily for fresh B2B leads.

Run it on Apify

What you can do with it

  • Accountants, bookkeepers, banks, insurers: reach companies in their first weeks, filtered by industry and area.
  • B2B SaaS and agencies: new software, e-commerce, construction or hospitality companies by SIC code.
  • Local services: new companies with a registered office in your postcode areas.
  • Market research: incorporation trends by industry, region and company type.
  • Compliance reminders: accounts and confirmation statement due dates for new companies.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'incorporatedLastDays': 7,
    'sicCodes': ['62012', '62020', '62090'],
    'location': 'London',
    'excludeDormant': True,
    'maxResults': 500}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/uk-companies-house-new-companies").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "incorporatedLastDays": 7,
    "sicCodes": [
        "62012",
        "62020",
        "62090"
    ],
    "location": "London",
    "excludeDormant": true,
    "maxResults": 500
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/uk-companies-house-new-companies').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~uk-companies-house-new-companies/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "incorporatedLastDays": 7,
  "sicCodes": [
    "62012",
    "62020",
    "62090"
  ],
  "location": "London",
  "excludeDormant": true,
  "maxResults": 500
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
