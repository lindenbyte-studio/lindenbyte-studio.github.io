SEO Audit Crawler: Bulk Technical Site Checker

Crawl one or many websites and get a per-page technical SEO audit: titles, meta descriptions, H1s, canonicals, noindex, broken internal links, duplicates, missing alt text, thin content. Pure HTTP, no browser, pay per page.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'startUrls': ['ghost.org'],
    'maxPagesPerSite': 25,
    'maxDepth': 3,
    'checkExternalLinks': True,
    'maxExternalLinksPerSite': 200}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/seo-audit-crawler-bulk-site-checker").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "startUrls": [
        "ghost.org"
    ],
    "maxPagesPerSite": 25,
    "maxDepth": 3,
    "checkExternalLinks": true,
    "maxExternalLinksPerSite": 200
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/seo-audit-crawler-bulk-site-checker').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~seo-audit-crawler-bulk-site-checker/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "startUrls": [
    "ghost.org"
  ],
  "maxPagesPerSite": 25,
  "maxDepth": 3,
  "checkExternalLinks": true,
  "maxExternalLinksPerSite": 200
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.

Ready-to-run example tasks

Each one opens on Apify with the input already filled in.

  • Quick SEO health check (25 pages)
    Audit the first 25 pages of a website for technical SEO issues: missing titles and meta descriptions, multiple H1s, broken internal and external links, noindex, missing alt text, thin content.
  • Competitor SEO comparison (3 sites)
    Crawl your site and two competitors side by side (20 pages each) and compare average SEO score, issue counts and duplicate titles per site in the summary rows.
  • Broken link checker: internal and external links
    Crawl a site and find broken links: internal links to pages that return errors and outbound links that return 404/410/5xx, point to dead domains or fail TLS.
  • SEO audit of one site section (blog only)
    Audit only one section of a site, here the blog, by following URLs that match an include pattern.
  • Find duplicate titles and meta descriptions
    Crawl up to 40 pages of a site and group pages that share the same title, meta description or H1.
  • Post-migration SEO check: noindex, canonicals, redirects
    After a redesign or migration, check that pages are not left on noindex, canonicals point to the right URLs, internal links do not go through redirects and nothing returns errors.
