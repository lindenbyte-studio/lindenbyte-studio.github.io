Google Ads Transparency Center Scraper: Competitor Ads

Get every ad an advertiser runs on Google (search, YouTube, display) from the Ads Transparency Center, by name, domain or ID. Filter by region, format and date; schedule for new-ad alerts.

Run it on Apify

What you can do with it

  • Competitor ad monitoring: schedule it daily with newAdsLastDays: 1 to get only the ads a competitor launched since yesterday.
  • Creative swipe file: image URLs, preview links and a deep link to each ad on Google's own page.
  • Advertiser lead lists: find which companies advertise in a region and how long they have been running ads.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'queries': ['shopify.com'],
    'region': 'anywhere',
    'format': 'video',
    'maxAdsPerAdvertiser': 100}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/google-ads-transparency-scraper").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "queries": [
        "shopify.com"
    ],
    "region": "anywhere",
    "format": "video",
    "maxAdsPerAdvertiser": 100
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/google-ads-transparency-scraper').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~google-ads-transparency-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "queries": [
    "shopify.com"
  ],
  "region": "anywhere",
  "format": "video",
  "maxAdsPerAdvertiser": 100
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
