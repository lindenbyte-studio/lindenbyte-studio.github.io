RSS & Atom Feed Monitor - New Items Only + Feed Finder

Read any RSS, Atom, RDF or JSON Feed (or just paste a website / YouTube channel URL and it finds the feed). Schedule it and get only NEW items since the last run, with keyword and date filters. Pay only for new items.

Run it on Apify

What you can do with it

  • Content monitoring. Track industry blogs, newsletters, changelogs and documentation updates.
  • Competitor blog watch. Get every new post from competitors' blogs the day it is published (pair it with our Sitemap Monitor for pages that are not in a feed).
  • News alerts to Slack, email, Zapier or Make. Schedule the Actor and connect an integration or webhook ("Run succeeded", then read the dataset). Only new items arrive, so each alert is new.
  • Podcast new-episode tracking. Get the audio enclosure URL, file size and episode artwork for every new episode.
  • YouTube upload alerts. Paste channel URLs and get every new video with its link, description and thumbnail.
  • GitHub release tracking. Use https://github.com/<owner>/<repo>/releases.atom to follow releases of the libraries you depend on.
  • Security advisories. Monitor vendor and distribution advisory feeds, with keywords for the products you run.
  • Feed finder. Find the RSS feed of hundreds of websites at once, for a reader, an aggregator or a lead list of active blogs.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'startUrls': [   'https://wordpress.org/news/',
                     'https://blog.cloudflare.com/',
                     'https://github.blog/',
                     'https://blog.apify.com/'],
    'onlyNewItems': True,
    'emitOnBaseline': True,
    'stateKey': 'competitor-blogs',
    'maxItemsPerFeed': 10}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/rss-feed-monitor-new-items").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "startUrls": [
        "https://wordpress.org/news/",
        "https://blog.cloudflare.com/",
        "https://github.blog/",
        "https://blog.apify.com/"
    ],
    "onlyNewItems": true,
    "emitOnBaseline": true,
    "stateKey": "competitor-blogs",
    "maxItemsPerFeed": 10
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/rss-feed-monitor-new-items').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~rss-feed-monitor-new-items/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "startUrls": [
    "https://wordpress.org/news/",
    "https://blog.cloudflare.com/",
    "https://github.blog/",
    "https://blog.apify.com/"
  ],
  "onlyNewItems": true,
  "emitOnBaseline": true,
  "stateKey": "competitor-blogs",
  "maxItemsPerFeed": 10
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
