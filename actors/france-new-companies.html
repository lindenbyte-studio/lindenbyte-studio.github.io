France New Company Finder (BODACC + SIRENE, by NAF & Dept)

Daily feed of newly registered French companies (legal entities only) from official BODACC creations, enriched with SIRENE: SIREN/SIRET, NAF, legal form, head office with GPS, employee range, capital, VAT number. Filter by date, NAF, département, region, legal form.

Run it on Apify

What you can do with it

  • Accountants (experts-comptables), banks, insurers: reach companies in their first weeks, by département and activity.
  • B2B SaaS, agencies, web designers: new software, e-commerce, construction or restaurant companies by NAF code.
  • Real-estate and wealth advisors: new SCIs and holding companies in your area.
  • Market research: creation trends by sector, legal form and region.
  • CRM hygiene and KYC: SIREN, SIRET and VAT number of new counterparties.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'publishedLastDays': 7,
    'departements': ['75'],
    'nafCodes': ['56.10A', '56.10C', '56.30Z'],
    'maxResults': 200}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/france-new-companies").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "publishedLastDays": 7,
    "departements": [
        "75"
    ],
    "nafCodes": [
        "56.10A",
        "56.10C",
        "56.30Z"
    ],
    "maxResults": 200
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/france-new-companies').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~france-new-companies/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "publishedLastDays": 7,
  "departements": [
    "75"
  ],
  "nafCodes": [
    "56.10A",
    "56.10C",
    "56.30Z"
  ],
  "maxResults": 200
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
