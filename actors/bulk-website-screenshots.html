Bulk Website Screenshots + PDF + Visual Change Detection

Screenshot hundreds of URLs per run: full page or viewport, desktop/laptop/tablet/mobile, PNG/JPEG/WebP, optional PDF. Hides cookie banners and chat widgets. Schedule it to detect visual changes since the last run.

Run it on Apify

What you can do with it

  • Website monitoring: see when a competitor changes pricing, homepage, landing pages or terms. Get a screenshot of the new version and of the previous one.
  • Visual QA and regression checks: capture every page of your site on every device after a deploy.
  • Agencies and SEO: client reports, before/after redesign snapshots, mobile-friendliness checks.
  • Archiving and compliance: dated full-page screenshots and PDFs of pages, ads and policies.
  • Thumbnails and previews for directories, link previews and dashboards.
  • AI and data pipelines: page images for vision models, alongside the title, final URL and HTTP status.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'urls': ['https://www.allbirds.com', 'https://nodejs.org/en'],
    'devices': ['desktop'],
    'compareWithPrevious': True,
    'changeThreshold': 2,
    'stateKey': 'example-competitors'}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/bulk-website-screenshots").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "urls": [
        "https://www.allbirds.com",
        "https://nodejs.org/en"
    ],
    "devices": [
        "desktop"
    ],
    "compareWithPrevious": true,
    "changeThreshold": 2,
    "stateKey": "example-competitors"
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/bulk-website-screenshots').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~bulk-website-screenshots/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "urls": [
    "https://www.allbirds.com",
    "https://nodejs.org/en"
  ],
  "devices": [
    "desktop"
  ],
  "compareWithPrevious": true,
  "changeThreshold": 2,
  "stateKey": "example-competitors"
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.
