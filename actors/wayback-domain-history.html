Bulk Domain History Checker (Wayback Machine)

Check the Wayback Machine history of many domains at once: first/last capture, archive age, captures per year, gaps, status codes, redirects to other sites, and archived homepage titles per year with spam, parked and language-change flags. For expired-domain due diligence and SEO.

Run it on Apify

What you can do with it

  • Expired / auction domain buying: check age, continuity and past use before you bid (GoDaddy Auctions, DropCatch, NameJet, SnapNames lists).
  • SEO and link building: spot domains with a spam past or a long dark period before using them, vet PBN or guest-post sites.
  • Brand and M&A research: when did a site launch, rebrand, redirect, go dark?
  • Academic and journalism research: archive coverage per year for a list of sites.

Run it from code

Get an API token in the Apify Console (Settings, API & Integrations) and replace <YOUR_APIFY_TOKEN>.

Python (apify-client)
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")

run_input = {   'domains': ['geocities.com', 'myspace.com', 'digg.com', 'friendster.com'],
    'fetchTitles': True}

# Start the Actor and wait for it to finish
run = client.actor("lindenbyte/wayback-domain-history").call(run_input=run_input)

# Read the results from the run's default dataset
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
JavaScript / Node.js (apify-client)
// npm install apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });

const input = {
    "domains": [
        "geocities.com",
        "myspace.com",
        "digg.com",
        "friendster.com"
    ],
    "fetchTitles": true
};

// Start the Actor and wait for it to finish
const run = await client.actor('lindenbyte/wayback-domain-history').call(input);

// Read the results from the run's default dataset
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
curl (synchronous run, returns the results)
# Runs the Actor synchronously and returns the dataset items as JSON
curl -X POST "https://api.apify.com/v2/acts/lindenbyte~wayback-domain-history/run-sync-get-dataset-items" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
  "domains": [
    "geocities.com",
    "myspace.com",
    "digg.com",
    "friendster.com"
  ],
  "fetchTitles": true
}'

Synchronous runs time out after 300 seconds; for bigger jobs start a normal run and read the dataset when it finishes.

Ready-to-run example tasks

Each one opens on Apify with the input already filled in.

  • Expired domain history check before you buy
    Bulk check domain age, first and last Wayback snapshot, past page titles and redirects to spot spammy or pharma history before you buy an expired domain.
  • Competitor domain age and archive history
    Bulk domain age checker: first archived date, number of snapshots per year and past titles for a list of competitor domains, from the Internet Archive.
  • List old pages of a website archived in the Wayback Machine
    Get the domain's archive summary plus one row per archived HTML page (first capture date, status and a Wayback link).
  • Domain redirect history: where did these sites point?
    Check whether domains were redirected to another site in the past and where to, year by year, from Wayback Machine homepage captures.
  • Website history in a date range (dot-com era example)
    Domain history limited to a range of years (here 1998 to 2008): first and last capture, active years, gaps and the homepage title, description and language per year.
