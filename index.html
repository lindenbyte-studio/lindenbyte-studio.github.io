How to run them

Open an Actor on the Apify Store, fill in the input form and press Start, or call it from code with the Python or JavaScript API client (each docs page here has copy-paste snippets). Runs can be scheduled and connected to Slack, email, Google Sheets, Zapier, Make or n8n through Apify integrations. Questions or bugs: use the Issues tab on the Actor's Store page.
